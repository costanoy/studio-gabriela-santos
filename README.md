# Studio Gabriela Santos

Site institucional de um estúdio de estética corporal e facial em Goianésia-GO, feito para um cliente.

**No ar em:** [studiogabrielasantos.com.br](https://studiogabrielasantos.com.br)

## O que tem

- Apresentação do estúdio e dos procedimentos
- Galeria de antes e depois com comparador interativo
- Cursos e depoimentos
- Agendamento direto pelo WhatsApp
- SEO: títulos e descrições por página, `sitemap.xml`, `robots.txt` e imagem de compartilhamento

## Tecnologias

HTML, CSS e JavaScript puros, sem etapa de build.

## Como rodar

Abra o `index.html` no navegador, ou sirva a pasta com qualquer servidor estático:

```bash
npx serve .
```

## Arquivos

| Caminho | O que é |
|---|---|
| `index.html` | Página inicial |
| `resultados.html` | Resultados (antes e depois) |
| `assets/` | Imagens, fontes e vídeo de apresentação |
| `robots.txt`, `sitemap.xml` | Indexação |
